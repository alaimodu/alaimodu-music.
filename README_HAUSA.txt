ALAIMODU MUSIC — sigar farko

Abubuwan da ke ciki:
- index.html: shafin app
- assets/logo.png: hoton logo da aka bayar
- manifest.webmanifest da sw.js: PWA install/offline shell

Yadda ake gwadawa:
1. A ɗora wannan folder a HTTPS hosting (misali GitHub Pages ko wani hosting da ka mallaka).
2. Buɗe adireshin shafin a Chrome a Android.
3. Zaɓi menu na Chrome > Install app ko Add to Home screen.
4. App ɗin yana amfani da Jamendo API read-only demo client ID domin gwaji.
5. Kafin wallafa shi ga jama'a, ƙirƙiri naka developer app a https://devportal.jamendo.com/ sannan ka maye gurbin CLIENT_ID a index.html da client ID ɗinka.

Muhimmi:
- Wannan sigar farko ce (PWA), ba APK ba tukuna.
- Jamendo ba ya ba da dukkan waƙoƙin duniya; yana ba da kundin waƙoƙin da ke cikin sabis ɗinsa.
- Ka bi lasisin kowace waƙa da sharuɗɗan API kafin amfani ko wallafa app.
- Hoton profile da aka zaɓa yana zama a browser ɗin wannan na'ura a wannan sigar; ba a tura shi zuwa server.
